# Grand Theft Auto VI Guide

An unofficial Leonida field guide for Grand Theft Auto VI: Ultimate Edition unlocks, story missions, collectibles, vehicles, weapons, properties, and more.

Live site: https://dpalcic-create.github.io/gta6-guide/

Open `index.html` in any browser to use it offline. Progress is saved in that browser only.

Compiled November 23, 2026, four days after the November 19, 2026 launch on PlayStation 5 and Xbox Series X|S. Unconfirmed details are marked in the guide. Sources are listed on the Sources tab.

The site includes a Mandy portrait as the home-screen icon (`apple-touch-icon.png`) and a web app manifest so it can be saved to an iPhone home screen.
